# AVERON Content Studio

Open `admin.html` locally (or on localhost) to manage the static prototype without editing HTML by hand.

## Products
Edit product names, pricing, category, colour, copy and up to three product images.

## Banners
Edit the large homepage Hero and the “Timeless by Design” editorial banner, including image, headings, subtitle, CTA text and CTA link.

## Mini Banners
Edit the smaller homepage visual areas independently:
- Refined Essentials editorial visual
- Clothing category tile
- Jackets category tile
- Trousers category tile
- Accessories category tile
- The City Edit
- The Weekend Edit

Images are resized/compressed before being stored. Desktop and mobile read the same saved content, so one edit updates both responsive layouts.

## Static-build limitation
Content is stored in this browser's localStorage. This is ideal for local design/content preparation but is not a production CMS. A real deployment should connect this interface to authenticated backend APIs, database/object storage and a CDN.
