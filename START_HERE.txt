AVERON — LOCAL TESTING

1. Extract the ENTIRE AVERON_CSS_LOCAL_FIXED folder from the ZIP before opening the site.
2. Do NOT open index.html directly from inside WinRAR/7-Zip. The browser needs styles.css, JavaScript and the assets/ folder beside the HTML files.
3. After extraction, open index.html.

Folder structure must stay intact:
index.html
styles.css
app.js / other .js files
assets/
  favicon.png
  logo-navy.png
  logo-white.png

For production, serve the folder through HTTPS instead of file://.
