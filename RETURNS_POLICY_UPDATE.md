# AVERON returns-policy update — 19 August 2026

Reviewed against current UK government guidance for online/distance sales. Changes in this build:

- preserved the 14-day statutory cancellation right for eligible online purchases;
- clarified that the cancellation period generally starts the day after receipt and that goods are generally returned within a further 14 days after cancellation;
- retained AVERON's additional voluntary 30-day return window;
- made customer-paid return postage for non-faulty change-of-mind / size / colour returns explicit before checkout, where legally permitted;
- removed wording that could imply clothing must remain completely unused, preserving reasonable shop-like inspection/trying-on;
- added a model cancellation form and made clear that customers do not have to use it;
- clarified standard outbound-delivery reimbursement for statutory cancellation and no arbitrary restocking/cancellation fee;
- separated faulty/damaged/incorrect/misdescribed goods from change-of-mind returns;
- stated explicitly that CJ/supplier return limitations do not reduce the customer's rights against AVERON.
