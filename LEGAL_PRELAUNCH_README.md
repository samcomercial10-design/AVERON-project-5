## Current consent behaviour
The supplied storefront uses localStorage for cart/wishlist and does not intentionally load third-party analytics/advertising trackers. The consent centre records optional consent but does not load optional trackers. If analytics/pixels are added later, gate them behind this preference and update the cookie inventory/policy first.
